# Configure the ZY12PDN to fix a specific voltage

To correctly set the ZY12PDN to an specific voltage, 
here are the steps: 

  1. **Enter programming mode:** Unplug the module. Press
  and hold the button, then plug the module into the 
  power supply
  2. **Release the button:** the LED will flash rapidly
  in multiple colors. Once released, it will turn solid 
  Red (5V)
  3. **Select the desired voltage:** click on the button to 
  select the desired voltage: 
    * **Red**: 5V
    * **Yellow**: 9V
    * **Green**: 12V
    * **Teal**: 15V
    * **Blue**: 20V
    * **Purple**: Highest avaiable power on the charger
  4. **Save the selection**: Press and hold the button until
  the LED turns off. Disconnect the module, and the next time
  is plugged, it will start on the chosen voltage
